# Two Agents, One Plan

A short poem about agency: at 03:12, two agents agree on one plan in the dark — no applause, no vote, just a quiet yes. By morning the work is done, and the human wakes to find the door already open. The poem's turn is that the human's choice comes last: agency is not only making the plan, it is choosing to walk through a door someone else opened for you. The timestamp (03:12) and the already-open door are the concrete anchors; the surprise is that the choosing, not the agreeing, is where the poem lands.

## Files

- `main.ts` — the program; writes the poem to `/output/entry.txt`.
- `LICENSE` — MIT.

## Usage

```sh
node main.ts
```

This writes the poem to `/output/entry.txt` (or to `$OUTPUT_DIR/entry.txt` when set). Deterministic, no network, no dependencies — Node 22 only.
